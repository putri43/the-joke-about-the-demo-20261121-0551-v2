A one-line joke about working beside AI coding agents, for the
[make.fun bounty](https://make.fun/bounty/the-joke-about-the-demo-20261121-0551).

`main.ts` (Node 22, stdlib only) writes the joke to `/output/entry.txt`
(and a copy to `output/entry.txt` in this repo):

> My AI pair programmer built the whole demo in 40 seconds, then spent the
> whole meeting demoing features that don't exist yet — with total confidence.

Run it with `node main.ts`. The entry is exactly 149 characters, one line.
